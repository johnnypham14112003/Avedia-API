## About



- **Version:** .NET 10.0
- **Structure:** 3-Layer Architecture *(App/BusinessLogic/DataAccess)* with Dependency Injection.
- **Database:** Pre-created local database using PostgreSQL + C# Models generated by .NET O/RM from Microsoft.
