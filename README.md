## About



- **Version:** .NET 10.0
- **Structure:** 3-Layer Architecture *(App/BusinessLogic/DataAccess)* with Dependency Injection.
- **Database:** Pre-created local database using PostgreSQL + C# Models generated by .NET O/RM from Microsoft.

## How to use
### Create database and scraffold

dotnet ef dbcontext scaffold "Host=localhost;Database=avedia;Username=postgres;Password=your_password" Npgsql.EntityFrameworkCore.PostgreSQL -o Models -c AVEDbContext

## Some Note In Project
- `ControllerBase` is use for API project while `Controller` is for Server-Side rendering project.
- `Microsoft.IdentityModel.JsonWebTokens` is the newer and suggested replacing the `System.IdentityModel.Tokens.Jwt` from .NET 8
- In [TokenServic.cs](http), there 2 way of declare claim to `SecurityTokenDescriptor`. *Choose 1 only (Subject / Claims), if set both, Claims will override Subject [*reference](https://learn.microsoft.com/en-us/dotnet/api/microsoft.identitymodel.tokens.securitytokendescriptor?view=msal-web-dotnet-latest#properties)*

```
var claims = new[]
{
    new Claim(ClaimTypes.Name, account.UserName),
    new Claim(ClaimTypes.Email, account.Email),
    new Claim(ClaimTypes.Role, account.Role),
    new Claim("Id", account.Id.ToString())
};
var tokenDescriptor = new SecurityTokenDescriptor
{
    ...
    Subject = new ClaimsIdentity(claims),
    //Claims = claims.ToDictionary(c => c.Type, c => (object)c.Value),
    ...
};
```
