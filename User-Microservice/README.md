## About
A microservice project of Avedia-API system using ASP.NET Core gRPC Service to manage data of User, Contribution Request, Notification, Badge using DbContext (Entity Framework O/RM)

- **Version:** .NET 10.0
- **Structure:** 3-Layer Architecture *(App/BusinessLogic/DataAccess)* with Dependency Injection.
- **Database:** Pre-created local database using PostgreSQL + C# Models generated by DOTNET EF Scraffold.

## How to use
### Create database and scraffold
```
dotnet ef dbcontext scaffold "Host=localhost;Database=avedia;Username=postgres;Password=your_password" Npgsql.EntityFrameworkCore.PostgreSQL -o Models -c AVEDbContext
```
